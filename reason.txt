Depth



Think of it like this:

Mission:

Start at the root.

Walk until you find the value.

Count every step you take.

When you arrive...

That's the depth.

For example,

        50
       /  \
     30    70
    /
   20

Looking for 20.

Start at 50.

↓

Move to 30.
Step = 1

↓

Move to 20.
Step = 2

Found it.

Depth = 2

That's all.


Height

Height is almost the opposite mission.

Mission:

Find the node.

Now stand on it.

Look down both sides.

Whichever side reaches the furthest leaf...

Count those steps.

That's the height.

      
      What does "balanced" mean?

A tree is balanced if every node satisfies this rule:

The difference between the height of its left subtree 
and the height of its right subtree is no more than 1.

That means:

|leftHeight - rightHeight| <= 1

Notice something important:

It doesn't say the root.

It says every node.

Balanced Tree

// Checks if the tree's left and right subtrees differ in height by no more than 1
isBalanced() {
    const cur = this.root
    if(!this._getHeight(cur)) return false


  // Helper to recursively check balance state
  const checkBalance = (node) => {
    if (!node) return true;

    const leftHeight = getHeight(node.left);
    const rightHeight = getHeight(node.right);

    // Check if current node is balanced
    const currentBalanced = Math.abs(leftHeight - rightHeight) <= 1;

    // Tree is balanced only if current node AND all subtrees are balanced
    return currentBalanced && checkBalance(node.left) && checkBalance(node.right);
  };

  return checkBalance(this.root);
}

// Reconstructs an unbalanced tree into a perfectly balanced tree
rebalance() {
  if (!this.root) return;

  // Step 1: Collect all values in sorted order using your In-Order method
  const sortedValues = [];
  this.inOrderForEach(data => sortedValues.push(data));

  // Step 2: Helper to build a balanced tree from the sorted array
  const buildTree = (start, end) => {
    if (start > end) return null;

    // Pick the middle element to keep left and right sides equal
    const mid = Math.floor((start + end) / 2);
    
    // Create a new node (adjust 'Node' to match your class name)
    const newNode = new Node(sortedValues[mid]); 

    // Recursively build the left and right halves
    newNode.left = buildTree(start, mid - 1);
    newNode.right = buildTree(mid + 1, end);

    return newNode;
  };

  // Step 3: Replace the old unbalanced root with the new balanced root
  this.root = buildTree(0, sortedValues.length - 1);
}

}
